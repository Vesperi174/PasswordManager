# 密码库 · 轻量本地密码管理器

一个**零第三方依赖**的桌面密码管理器：Python 标准库 + Tkinter 界面 + SQLite 存储。
双击 `run.bat` 就能用，账号与密码用你设置的主密码加密后保存在本机，不会上传到任何地方。

```
┌──────────────────────────────────────────────────────────────┐
│  密码库              [ 搜索… ]              ＋ 新建账号   ⋯  │
├──────────┬──────────────────┬────────────────────────────────┤
│ 全部账号 │ GitHub           │  GitHub                        │
│ ★ 收藏   │ octocat          │  开发 · 1 个关联               │
│ 分类     │ ───────────────  │  用户名  octocat      复制     │
│  开发    │ Gmail 主邮箱     │  邮箱    octocat@…    复制     │
│  邮箱    │ octocat@gmail.com│  密码    ●●●●●●●●  显示  复制  │
│ 标签     │ ───────────────  │  网址    github.com  复制      │
│  # 工作  │ Steam            │  关联账号                      │
│  # 常用  │ gamer            │  → [绑定邮箱] Gmail 主邮箱 移除│
└──────────┴──────────────────┴────────────────────────────────┘
```

## 功能

- **主密码解锁**：首次运行设置主密码，之后每次打开都需解锁；忘记无法找回，也没有后门。
- **账号 / 邮箱区分**：新建时先选类型——「账号」（登录名 + 密码）或「邮箱账号」（邮箱地址 + 密码）。
  侧栏可按类型筛选，列表与详情都会标出类型。
- **账号管理**：名称、用户名、邮箱、密码、网址、分类、标签、备注、收藏。
- **账号关联（重点）**：任意两个账号之间可以建立关系，例如
  - `GitHub` 的**绑定邮箱**是 `Gmail 主邮箱`
  - `Gmail` 的**主账号**是某个手机号/主号
  - 两条记录之间的**子账号**、**恢复邮箱**、**两步验证**、**同人账号**、**支付方式**……

  详情页会把关联双向展示（`→` 表示"我方指向对方"，`←` 表示"对方指向我方"），可点目标账号直接跳转。
- **邮箱自动互相关联**：新建账号填邮箱时——
  - 已有同地址邮箱账号 → 勾选后自动建立「绑定邮箱」关联（账号 → 邮箱）；
  - 还没有对应邮箱账号 → 可勾选"一并创建邮箱账号"，保存后自动创建并互相绑定；
  - 直接新建邮箱账号时 → 会自动提示"哪些账号正在用这个邮箱"，保存后反向关联（那些账号 → 本邮箱）。
- **邮箱后缀 → 登录网址自动识别**：填 `xxx@qq.com` 自动带出 `mail.qq.com`，`@gmail.com` 带出 `mail.google.com`，
  `@163.com`、`@outlook.com`、`@yahoo.com`、`@icloud.com` 等常见服务商都支持；
  自己填过的网址不会被覆盖，只提示"点此替换"；识别不到时也会明确提示手动填写。
- **搜索与筛选**：按名称/用户名/邮箱/网址/分类/备注/标签搜索；侧栏按类型、分类、标签、收藏筛选。
- **密码生成器**：`secrets` 系统级随机源，可选长度 8–64 与字符类型（自动避开 `0O1lI` 等易混字符）。
- **安全细节**：复制密码到剪贴板 30 秒后自动清除；闲置 15 分钟自动锁定；连续输错逐步冷却。
- **账号组**：把同一套账号打包成一行（例如 Apex + EA + Steam + 绑定邮箱），列表不再臃肿；
  组行可展开/收起，组详情里每个成员都能单独复制密码，成员账号本身完全独立。
- **防丢数据**：解锁与退出时自动生成加密备份（默认存到项目目录之外，保留最近 10 份），
  数据文件丢失时启动界面会出现「从备份恢复」提示；菜单里也能手动备份/恢复、导出明文 JSON。
- **检测更新（v1.1.0 新增）**：菜单 `⋯ → 检测更新…` 可在应用内检查新版本、直接下载安装并重启，
  不需要打开浏览器或 GitHub；更新只替换程序文件，账号数据不受影响，安装前自动备份、失败自动回滚。

## 快速开始

要求：Python 3.10+（Windows 官方安装包自带 tkinter）。

1. 双击 **`run.bat`**（无控制台窗口）；或命令行执行：

   ```bat
   python app.py
   ```

2. 首次运行 → 设置主密码（至少 8 位，建议 12 位以上并混合大小写、数字、符号）。
3. 点右上角「＋ 新建账号」开始录入。

数据默认保存在 `data/vault.db`（相对程序目录）。

### 命令行参数

```bat
python app.py --data D:\我的密码库 --idle-minutes 5   :: 自定义数据目录与锁定时间
python app.py --version                              :: 查看版本
python app.py                                        :: 默认 ./data，闲置 15 分钟锁定
```

### 检测更新（应用内在线更新）

1. 解锁后点右上角 `⋯` → **检测更新…**；
2. 程序会读取仓库里的 `version.json`（HTTPS，不经浏览器），显示当前版本与最新版本；
3. 有新版本时点「**下载并更新**」，会：
   - 把当前程序文件打包备份到 `data/backups/update-backup-*.zip`；
   - 下载新版本并只替换程序文件（`app.py`、`pm/`、`tools/`、文档等）；
   - 安装失败自动回滚；`data/`（账号库）与 `.git/` 不会被触碰；
4. 完成后点「立即重启」即可使用新版本。

> 更新源是本仓库 main 分支上的 `version.json`，其中 `download_url` 指向 **main 分支的归档压缩包**；
> 发布新版本时只需：把 `pm/__init__.py` 的版本号 + `version.json` 更新并推送到 main，
> 旧版本用户就能检测到更新（不需要打 tag、也不需要发 Release）。
> 检测时会依次尝试 raw、GitHub API、网页 raw 三个地址，某个地址被墙/被代理拦截也能继续。

## 界面怎么用

- **左侧栏**：全部 / 类型（账号、邮箱账号）/ 收藏 / 分类 / 标签，点击即筛选，括号里的数字是数量。
- **中间列表**：单击查看详情，双击编辑，右键有「复制密码 / 复制用户名 / 编辑 / 删除」。
  邮箱账号的头像是绿色并带「邮箱」小标记，普通账号是蓝色；账号组是紫色「组」并带成员数。
- **账号组行**：点左侧 ▸ / ▾ 展开收起成员，点组名看组详情，双击或右键可编辑/删除组。
- **右侧详情**：
  - 「显示」看密码明文，「复制」放进剪贴板（30 秒后自动清空）。
  - 「☆ 收藏」置顶常用账号。
  - 「＋ 添加关联」选择关联类型与目标账号。
  - 网址可以直接点击在浏览器打开。
- **顶栏搜索**：`Ctrl+F` 聚焦搜索框，`Esc` 关闭弹窗。
- **右上角「⋯」**：修改主密码、导出明文备份、备份加密副本、从备份恢复、立即锁定、关于。

### 账号与邮箱怎么区分、怎么互相关联

新建账号时最上面有类型切换：**账号** / **邮箱账号**。

1. **建邮箱账号**：类型选「邮箱账号」，填邮箱名称与邮箱地址 → 保存。
   它就是一个独立的"邮箱"实体，不会和普通登录账号混在一起。
2. **普通账号绑定它**：新建「账号」，在"绑定邮箱"里填该邮箱地址 → 弹窗会自动提示
   `检测到同地址的邮箱账号`，勾选后保存，自动建立「绑定邮箱」关联。
3. **顺手创建邮箱账号**：如果这个邮箱还没有对应账号，勾选
   `创建邮箱账号「xxx」并建立「绑定邮箱」关联`，保存时会一并创建并互相绑定。
4. **反向也行**：先建好普通账号（邮箱填 `xxx`），再新建一个「邮箱账号」，
   弹窗会提示"以下账号使用这个邮箱"，勾选保存后这些账号会自动关联到该邮箱。

关联是双向展示的：在 `GitHub` 详情看到 `→ [绑定邮箱] Gmail 主邮箱`，
在 `Gmail` 详情就会看到 `← [绑定邮箱] GitHub`，点名称可互相跳转。
侧栏「类型」可以把账号和邮箱账号分开浏览。

### 登录账号就是邮箱地址，怎么录？

很多网站（网易云音乐、部分论坛/服务）直接用**邮箱地址当登录名**。这种情况这样录：

1. 新建账号 → 类型保持「**账号**」（不要选邮箱账号，邮箱账号代表"邮箱本身"）；
2. 「绑定邮箱」填入邮箱地址，再勾选「**账号就是邮箱地址（自动同步到用户名）**」——
   用户名会自动变成该邮箱，之后改邮箱也会跟着同步（取消勾选就停止同步）；
3. 如果库里已有同地址的「邮箱账号」，保存时会提示并**自动建立「绑定邮箱」关联**；
   没有的话可以勾选"一并创建邮箱账号并互相关联"；
4. 保存后详情里"用户名"和"邮箱"都显示这个地址，搜索、复制、关联都照常可用。

**密码是分开的**：网站账号的密码存在它自己的记录里，邮箱账号的密码存在「邮箱账号」那条记录里，
勾选「账号就是邮箱地址」只同步账号名，**永远不会同步或覆盖密码**。
在网站账号详情的「关联账号」里，可以点「复制密码」直接取到邮箱账号自己的密码（提示会说明是谁的密码）。

编辑已有账号时，如果它的用户名与邮箱相同，会**自动勾选**这个选项，方便核对。
如果某个网站你不想把邮箱存成"绑定邮箱"，也可以只填用户名（邮箱地址）+ 密码，不做关联。

### 账号组（把多个账号打包成一行）

比如玩 Apex 需要：Apex 账号 + EA 账号 + Steam 账号 + 绑定邮箱，四个账号常驻列表太占地方。
把它们放进一个账号组：

1. 先把这几个账号都添加进库里；
2. 点右上角「⋯」→「**新建账号组…**」，填组名（如「Apex 游戏组」）并勾选这 4 个账号；
3. 列表里现在只显示一行紫色「组」条目，点行首 ▸ / ▾ 展开或收起成员；
4. 点组行查看组详情：组名、成员列表，每个成员都能「复制密码」或「打开」查看；
5. 双击组行或右键「编辑账号组」可改名字、加减成员；「删除账号组」只解散组，不会删除账号；
6. 搜索或按分类/标签筛选时，组会自动展开为平铺结果，方便直接找到某个成员。

组内成员账号完全独立：各自的密码、网址、关联关系都保留，只是列表里折叠显示；
组名和备注同样用主密码加密后写入数据库，不落明文。

### 邮箱后缀自动识别登录网址

在新建/编辑弹窗里填邮箱时，网址栏会自动识别并按需填写：

| 邮箱后缀 | 自动填入 |
| --- | --- |
| `@qq.com` / `@foxmail.com` | https://mail.qq.com |
| `@163.com` / `@126.com` / `@yeah.net` | https://mail.163.com 等网易邮箱 |
| `@gmail.com` | https://mail.google.com |
| `@outlook.com` / `@hotmail.com` / `@live.com` | https://outlook.live.com/mail/ |
| `@sina.com` / `@sohu.com` | 新浪 / 搜狐邮箱 |
| `@yahoo.com` / `@icloud.com` | Yahoo 邮箱 / iCloud 邮箱 |

- 网址为空时直接填入，并在下面提示「已根据邮箱后缀自动填写 XX 登录页」。
- 你已经填了别的网址时**不会覆盖**，只提示「识别到 XX 登录页：…（点此替换）」，点一下就换。
- 换成识别不到的域名时，会把上次自动填入的地址清空，避免留下错误网址。
- 保存后，若账号没有网址，详情页会多出一行「登录页 · 打开 XX 登录页」，可直接在浏览器打开。
- 服务商映射表在 `pm/util.py` 的 `EMAIL_PROVIDERS` 里，想加新邮箱改这里即可（支持子域名匹配，如 `mail.qq.com`）。

## 安全说明

| 项目 | 做法 |
| --- | --- |
| 密钥派生 | PBKDF2-HMAC-SHA256，600,000 次迭代，16 字节随机盐 |
| 记录加密 | ChaCha20-Poly1305 AEAD（RFC 8439），逐条加密，认证失败即拒绝解密 |
| 落盘内容 | SQLite 中只有密文、时间戳与关联 id；标题、用户名、邮箱、备注、账号组名均不以明文落盘 |
| 主密码 | 从不保存；只存一个用派生密钥加密的验证令牌 |
| 内存 | 明文仅在解锁后的进程内存中，锁定或退出立即丢弃 |
| 防爆破 | 连续输错 5 次后开始冷却（5 秒起逐步翻倍，最长 300 秒） |
| 剪贴板 | 复制后 30 秒自动清除 |
| 备份 | 自动备份与手动备份都是加密后的 `.db`，不落明文 |

实现细节：`pm/crypto.py` 是纯标准库的 ChaCha20/Poly1305 实现，已用 RFC 8439 官方向量校验
（`tools/selftest.py`）；`tools/store_test.py` 还会断言数据库文件里搜不到明文。

**已知局限**（请知悉）：本工具不防"能读取本机进程内存、键盘记录、系统级木马"的攻击者；
导出的 JSON 备份是明文，请妥善保管并在用完后删除。

## 备份与恢复

程序做了三层保护，避免"数据文件被删就全没了"：

1. **自动加密备份**：每次解锁和退出前，自动把加密过的整库复制一份到
   `%LOCALAPPDATA%\PasswordVault\backups\`（Windows；其他系统为 `~/.local/share` 旁边的默认目录），
   文件名形如 `vault-20261028-114530.db`，只保留最近 **10** 份。
   这个目录**故意放在项目文件夹之外**，所以即使整个 `data/` 被误删，备份仍然在。
2. **启动时自动提示恢复**：如果发现 `vault.db` 不存在/是空的，而备份目录里有历史库，
   启动界面顶部会出现「检测到历史加密备份 · 从备份恢复」的提示条，点一下即可恢复。
3. **手动备份 / 恢复**：`⋯` 菜单 →「备份加密副本…」保存一份到任意文件夹；
   「从备份恢复…」选择 `vault-*.db` 文件即可替换当前库（会用该备份的主密码解锁）。

> 注意：备份文件本身是主密码加密的 `.db`，恢复时需要**对应那份备份的主密码**。
> 修改主密码后，旧备份仍用旧主密码；想统一的话重新解锁一次生成新备份即可。

- 备份：把 `data/` 整个复制走（或配合上面的自动备份）。
- 换电脑：拷走 `data/` 即可，主密码不变。
- 数据文件被误删：先看启动界面的恢复提示；也可以从
  `%LOCALAPPDATA%\PasswordVault\backups\` 里挑一份 `vault-*.db` 放回 `data/` 再启动。
- 如果连备份目录也被清空：检查「此电脑 → 右键属性 → 以前的版本」，或用微软的
  Windows File Recovery（`winfr`）尝试恢复 `vault.db`；请尽量少往该磁盘写新文件。

## 项目结构

```
PasswordManager/
├─ app.py                  # 程序入口（窗口启动、命令行参数）
├─ version.json            # 在线更新源：最新版本号 / 下载地址 / 更新说明
├─ run.bat                 # 双击启动（优先 pythonw，无控制台窗口）
├─ requirements.txt        # 说明：无第三方依赖
├─ pm/
│  ├─ crypto.py            # ChaCha20-Poly1305 + PBKDF2（纯标准库，RFC 8439）
│  ├─ store.py             # SQLite 加密存储、账号/关联/账号组的增删改查、主密码管理
│  ├─ update.py            # 检测更新、下载并替换程序文件（自动备份与回滚）
│  ├─ util.py              # 密码生成、强度评估、邮箱后缀识别、时间格式化
│  ├─ ui_kit.py            # 界面基础件：配色、字体、扁平按钮、可滚动容器
│  ├─ gui_app.py           # 解锁界面 + 主界面（三栏 / 账号组 / 备份恢复）
│  └─ gui_dialogs.py       # 账号编辑、关联、密码生成器、账号组、改主密码、检测更新、关于
├─ tools/
│  ├─ selftest.py          # 加密原语自检（RFC 8439 官方测试向量）
│  ├─ store_test.py        # 数据层自检（含"磁盘无明文"、备份、在线更新断言）
│  └─ gui_test.py          # 界面自检（真实创建窗口并驱动交互）
└─ data/vault.db           # 运行后自动生成
```

## 自检

```bat
python tools\selftest.py     :: 加密向量、篡改检测、性能
python tools\store_test.py    :: 增删改查、关联级联、锁定/改主密码、磁盘无明文
python tools\gui_test.py      :: 真实窗口驱动：新建/搜索/收藏/关联/锁定解锁
```

```bat
pip install pyinstaller
pyinstaller --noconsole --onefile --name 密码库 app.py
```
